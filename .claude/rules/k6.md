# k6 performance-test conventions

Editing a k6 script. The k6 suites live in `repos/trade-imports-performance-tests`: entry scripts are `src/suites/*.k6.js`, and the modules they import sit under `src/k6/`. A k6 script is still JavaScript, so `node.md` applies additively.

- Always on: `~/git/defra/trade-imports-workspace/.claude/rules/code-quality.md` holds the house rules inline (comments, ids, history, names, structure, tests, logging).
- Topic dir: `~/git/defra/trade-imports-workspace/docs/best-practices/k6/`
- Key file: `BEST_PRACTICES.md` — realistic load models, thresholds, tagging.
- Repo notes: `~/git/defra/trade-imports-workspace/docs/repos/trade-imports-performance-tests.md`.

Read `BEST_PRACTICES.md` before writing a k6 script. Do not copy its content into this file; only the house rules are written inline, in `code-quality.md`.
