## Summary
Adds a reusable multi-select search component (client script, macro, styles and README under `src/client/javascripts/components/` and `src/server/common/components/multi-select-search/`). The commodity search page uses it to refresh its results in place through a new results route. Result headings now read "Name (code)" and the selected chips show the Latin name alone. The no-JS path keeps the server-rendered search, and gains an "Update selected" button.

## Positive Observations
- The component sits outside the commodities feature, beside `accessible-autocomplete`, and is registered through `createAll` exactly as the sibling is. The ticket's reuse criterion is met.
- The results swap uses the server's own partial (`_results.njk`), so the JS and no-JS paths share one markup owner. The script falls back to a native submit when the fetch fails.
- The client test suite renders the real macro and mocks only `fetch` and the clock. The fit suite covers both paths, including races (Clear all then Save) proven by slowing the route.
- The `upload.fit.spec.js` flake fix and the `hub.fit.spec.js` move to the shared journey helper are sound.

## Test Coverage
- Unit tests: good for the controller and view-models, with some copied set-up (#36) and over-claiming titles (#35, #39). The client unit suite misses the no-results-region fallback, the rejected fetch, the constructor guard and click-to-reshow (#11). The Welsh singular/plural announcement is untested (#20).
- Integration tests: the fit coverage is broad. One URL check can never fail (#23), three titles over-claim (#24), and set-up is copied that belongs in `fit/live-animals-journey.js` (#26).

## Risk Assessment
**Overall Risk:** Medium
**Rationale:** The feature works and is well tested, but two client-script bugs need fixing before merge. A late refresh can steal focus (#63), and a latched native-submit flag leaves the page dead after Back from the bfcache (#4). Chip remove buttons can also share an accessible name (#28), and forced-colours mode hides the chip X (#45).

Signed-off check: no signed-off scenario or linked test is edited. The shared fit helper `expectSpeciesSelected` changed (it now checks the Latin-name chip). It is called during set-up by `consignment-details.fit.spec.js` "adds another species while preserving existing quantities", which is linked to SCN-COMMODITY-DETAILS-007-A/B (signed off 2026-11-11). The test body and the scenario's Then are unchanged, so this is not a trip, but it is worth a look.

Several items are designer questions, not code defects: chip design vs GOV.UK/MoJ (#62), the hover ring (#64), "1 result(s)" wording (#60), "Cow" vs the prototype's "Cattle" and the panel's code-only heading (#18), and the no-JS Update selected button (#30, ruled in trade-imports-workspace #9).
