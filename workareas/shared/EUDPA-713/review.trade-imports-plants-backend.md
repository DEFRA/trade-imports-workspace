## Summary
The PR applies the animals scoping to plants:
- `organisationId` on the aggregate
- the header filter
- finders filtered by organisation
- a 403 on another organisation's fulfilments

The ticket covers live animals. It says plants needs its own ticket that handles delegation (`onBehalfOfOrganisationId`), and this PR does not handle delegation.

## Positive Observations
- Every trader path filters by organisation in the query, and the service has the same shape as its animals twin.
- `NotificationIT` checks against real Mongo that another organisation cannot see a notification.

## Test Coverage
- **Unit tests: partial.**
  - The controller stubs match the organisation with `anyString()`, so a wrong organisation still passes.
  - The `stored()` fixture has no owner.
  - The 403 branch has no unit test.
- **Integration tests: partial.** Nothing tests:
  - cancel-amend from another organisation
  - that a copy belongs to the caller's organisation
  - the missing-header filter: the required `@RequestHeader` already returns 400, so the existing test passes without the filter

## Risk Assessment
**Overall Risk:** Medium
**Rationale:** The scoping is correct, but the unscoped finders are still on the repository. Delegation is also missing, and the ticket says plants will need it.
