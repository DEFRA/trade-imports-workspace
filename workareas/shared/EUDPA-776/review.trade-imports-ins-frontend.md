## Summary
Removes the consignment contact handshake from the address book: the registry entry, `isConsignmentContact`, the `CONSIGNMENT_CONTACT` add mode and its template branch. The production removal is correct. A request with the old fulfilment id now gets a 404 and a log line. But a rebase over main's 75aac72 and b9109426 kept the old test files, so the PR also deletes every germinal products add-address test and undoes main's fit refactor (#10).
