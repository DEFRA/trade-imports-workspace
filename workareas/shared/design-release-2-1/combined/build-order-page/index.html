Theme build order

The schematic

A theme sits one level below the last theme it waits on. Lines run top to bottom: the theme at the tail must land before the theme at the head can start. Where lines cross, nothing is implied — the crossing is only routing.

The theme register

“Follows” lists only the themes a theme waits on directly. Everything above those is inherited, so a theme near the foot of the schematic is effectively waiting on the whole programme.
