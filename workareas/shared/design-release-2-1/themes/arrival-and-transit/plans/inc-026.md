## 0. Decisions

1. **How the date label becomes medium.** Both repos' `kit.dateField()` hardcode `label.classes: 'govuk-label--s'`, and other pages use it too (animals: import-reason exit date and the documents date of issue). Add an optional `labelClasses` option, defaulting to `'govuk-label--s'`, to `kit.dateField()` in both repos. The two arrival-details pages pass `'govuk-label--m'`. Rejected: changing the default to `--m`, which would resize the import-reason and documents dates that this row does not cover.
2. **Placeholder 'Select a port' with JavaScript on.** The native select's empty option is never shown once accessible-autocomplete enhances it: the wrapper sets the input's default value to `''` when nothing is chosen, so the input is just empty. The ruling (ruling-sam-2026-10-09-pm-p1-010) says the placeholder follows the prototype "wherever the component can show it". The alphagov library has a documented `placeholder` option. So: (a) the empty option text becomes 'Select a port', which covers the no-JS select; and (b) the animals macro gets an optional `autocomplete.placeholder` param, rendered as a `data-placeholder` attribute. The animals client component passes it to the library as `placeholder`. Only port of entry sets it, so other autocompletes behave exactly as before (the library default is `''`). This is library configuration, not custom JavaScript that copies the prototype. Rejected: changing the empty option text alone. That would leave the JS-enhanced search box (what nearly every user sees, and what the E2E sees) with no placeholder, so the criterion would not hold.
3. **Plants gets no placeholder change.** The ruling for plants (ruling-sam-2026-10-09-pm-p3-034) names only the medium labels and the place of landing hint. Plants keeps its own data, so its 'Select a place of landing' empty option and its client component are left alone. Rejected: mirroring the `data-placeholder` plumbing into plants' duplicated component. The ruling doesn't ask for it, and frontends stay duplicated rather than kept in lockstep.
4. **The review card (check answers and the submitted notification view) also reads Air/Rail/Road/Sea.** The prototype's own review card shows 'Air' and 'Sea' (trace-prototype-dr2-1 review-card quotes: "Means of transport to the port of entry\nAir", "...\nSea"). If the page offered 'Road' and the review then said 'Road Vehicle', the trader would see a different answer from the one they picked. `CA/copy/copy.en.js` and `copy.cy.js` `means` change to match. Rejected: leaving the review on the old words, which the prototype contradicts.
5. **Welsh drafts.** `portOfEntry.port.hint` (cy) already opens 'Dewiswch' (which covers both Choose and Select), so it stays as it is. New drafts: placeholder 'Dewiswch borthladd'; means 'Awyr', 'Rheilffordd', 'Ffordd', 'Môr' (both the transport and check-answers bundles); lead-in 'Rhowch un o’r canlynol:'. Plants hint: 'Dewiswch ble bydd y tatws yn dod i mewn i Brydain Fawr. Dechreuwch deipio i chwilio yn ôl enw neu god y porthladd neu’r maes awyr.' Keep the existing MACHINE-DRAFT header line.
6. **Option order.** `transportReference.meansOfTransport()` already returns AIRPLANE, RAILWAY, ROAD_VEHICLE, VESSEL, so relabelling gives Air, Rail, Road, Sea in the required order. No change to `services/transport-reference/`. Codes, field names and the `port-of-entry` page address are unchanged (c-047, req-1807, req-1808).
7. **The plants place of landing hint reads 'Select where the potatoes will enter Great Britain. Start typing to search by port or airport name or code.'** This is criterion 8 verbatim.
8. **The tests repo's means constants** (`T/domain/animals/constants/means-of-transport.ts` `display`) move to 'Air'/'Rail'/'Road'/'Sea' so the domain model matches the page. The values are unchanged.
9. **Label size is not spec text.** `openspec/config.yaml` treats a CSS class that changes no title, question, wording, order or grouping as pure styling. Criteria 1 and 7 are pinned by tests only, and section 8 writes no scenario for them.

Claims checked against the live tree: every criterion's "before" state holds today. The labels are `govuk-label--s` (template and `kit.dateField`). The hint reads 'Choose where…', the placeholder 'Select port of entry', the options 'Airplane/Railway/Road Vehicle/Vessel', the lead-in 'To identify the means of transport, enter (one of the following):'. Plants labels are `--s` and its hint reads 'Where the potatoes will enter…'. The stored codes are AIRPLANE/RAILWAY/ROAD_VEHICLE/VESSEL, and the overland set is RAILWAY/ROAD_VEHICLE. Nothing in the row is wrong.
