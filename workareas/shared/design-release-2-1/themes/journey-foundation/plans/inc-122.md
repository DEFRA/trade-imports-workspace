## How the code stands today (checked against the tree)

- Both frontends render the strip in `src/server/app/shared/layout.njk` (`{% if journeyStrip %}` block, lines ~95-101), inside the content column and **before** `{% block journeyContent %}`. Every page's caption (`sectionCaption(caption)`) and H1 sit inside `journeyContent`, so the strip is already above the caption and heading. No reordering is needed.
- The strip view model is `journeyStrip(journey)` in `src/server/app/shared/kit.js` (animals line 52, plants line 59): `{ reference, status: { text, classes } }`. `kit.base()` puts it on every page built through `base`; the animals hub (`features/hub/controller.js:168`) and animals review (`features/check-answers/controller.js:117`) call `journeyStrip(journey)` directly; the plants hub and review go through `kit.base`.
- The AMEND tag text is the shared copy key `journeyStrip.amend` = `'Amending'` (cy `'Wrthi’n diwygio'`) in each frontend's `shared/copy.en.js` / `copy.cy.js`.
- Both dashboards build each card's status tag from `journeyStrip(journey).status` (`features/dashboard/view-model/row/index.js`), so the tag text change reaches the dashboard card as well.
- Today only the review offers cancel: `cancelAmendHref` in each review controller, rendered in `check-answers/template.njk` as a `Cancel amendment` link under the H1 (copy key `cancelAmend.link` in each review's copy).
- The cancel-amendment confirmation page exists in both sets (`features/cancel-amend/controller.js`, slug `cancel-amend`, a GET page whose confirm is a form POST — no JavaScript involved). Its "No/Go back" button returns to the review with the amendment still in progress; "Yes" restores the submitted answers and redirects to `notification-view?cancelled=1` (the read-only Submitted view).
- `copyFor` always resolves English today (no runtime locale switch). "With the service in Welsh" is therefore proved by the Welsh copy modules carrying Welsh values, as the rest of the service does.
- There is no `sets/germinal-products` in the animals frontend on this branch, and no germinal E2E spec in the tests repo reads 'Amending'.

## 0. Decisions

1. **The tag reads 'Amend' everywhere the AMEND state is shown, the dashboard card included.** Claim 40 of the 9 October afternoon ruling makes this the one sanctioned change to the shared strip, so the shared key `journeyStrip.amend` is changed in place (en `'Amend'`, cy `'Diwygio'`), in both frontends. This is the ruling's named exception to the "never reword shared copy in place" invariant. Because the dashboards read their tag from the same strip status, the dashboard card reads 'Amend' too — kept, not forked: one vocabulary for one state, and the spec already says the state is shown the same way "wherever a notification's state is displayed". Rejected: a dashboard-only 'Amending' key, which would split one state into two words.
2. **Cancel amend lives in the strip view model, not in each page.** `journeyStrip(journey)` gains `cancelAmend: { href, text }` when the journey's status is AMEND, and leaves the key `undefined` otherwise (so every existing `toEqual({ reference, status })` assertion on a draft/submitted strip stays true). The text comes from a new shared key `journeyStrip.cancelAmend` (en `'Cancel amend'`, cy `'Canslo diwygio'`). The href is `pagePath(journey.journeyId, CANCEL_AMEND_SLUG)`. Rejected: passing `cancelAmendHref` from each controller (repeats per page and misses pages).
3. **`CANCEL_AMEND_SLUG` moves into `shared/kit.js`** as an export beside `CYA_SLUG`, and each set's `cancel-amend/controller.js` imports it instead of declaring its own. Shared kit already names `CYA_SLUG`, so a slug in L2 has precedent; no set vocabulary or copy enters L2 beyond the shared strip copy that is already there.
4. **The control is a plain link** (`<a class="govuk-link">`) to the confirmation page — a GET, so it works with JavaScript off, and a page, never a dialog (ruling p1-086, invariants on pop-ups and no-JS).
5. **The confirmation page itself does not offer Cancel amend** (a link to the page you are on). `journeyStrip(journey, { offerCancelAmend = true } = {})` takes an option; `kit.base` passes through a new `offerCancelAmend` option (default `true`); each set's `cancel-amend/controller.js` `render` passes `offerCancelAmend: false`. The strip there still shows the 'Amend' tag and reference.
6. **The review's own 'Cancel amendment' link under the heading is removed** in both sets: the strip now carries the control on the review, and DR2.1 shows one control in the bar. `cancelAmendHref` leaves both review controllers, the `{% if cancelAmendHref %}` block leaves both review templates, and the now-unused `cancelAmend.link` key leaves both review copy modules (en and cy). `cancelAmend.successTitle`/`successBody` stay.
7. **'Go back' on the confirmation page still returns to the review**, whichever page the user came from. The criterion asks only that it "leaves the amendment in progress", which it does; returning to the originating page is inc-121's rewording territory. Rejected: a `returnTo` parameter now.
8. **Dashboard actions keep 'Cancel amendment'** (`dashboard/copy` `actions.cancelAmend`). The ruling changes the strip, not the dashboard's action wording.
9. **Germinal products** (criterion 14): the set does not exist on this branch and no germinal E2E reads 'Amending'. The single change in the shared strip is what a future germinal set inherits; nothing germinal is built here. The criterion's "end-to-end checks that read 'Amending' read 'Amend'" is met by moving every such check in the tests repo (all animals and plants) to 'Amend'.
10. **Layout markup**: within the existing `app-journey-strip` div, after the reference span, render `{% if journeyStrip.cancelAmend %}<a class="govuk-link govuk-!-font-size-19 govuk-!-margin-left-2" href="{{ journeyStrip.cancelAmend.href }}">{{ journeyStrip.cancelAmend.text }}</a>{% endif %}`. govuk-* utilities only, no new CSS.
11. **Test page objects**: the strip, its tag and its Cancel amend link move onto the shared `NotificationPage` in `page-objects/shared/base-page.ts` as `journeyStrip`, `statusTag` and `cancelAmend`, so every notification page object (question pages included) has them. The duplicate `journeyStrip`/`statusTag` getters on the subclasses go. `AnimalsNotificationViewPage.cancelAmendment` is removed and its callers move to `cancelAmend`.
12. **Integration proof extends the existing cancel-amend specs** (animals `cancel-amend-ui.spec.ts`, plants `review.spec.ts`) rather than adding new files, following their existing set-up (seeded amendment for animals, a UI-built one for plants).
