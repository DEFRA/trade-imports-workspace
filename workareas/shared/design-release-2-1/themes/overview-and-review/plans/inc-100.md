## Summary

Every acceptance criterion already holds on the branch. The arrival-and-transit theme (animals frontend #402, and the means-of-transport row that replaced the earlier one) landed the rule and the overview behaviour this row asks for:

- the rule for when transit countries are owed is the `transitedCountries` obligation, in scope only for `RAILWAY` or `ROAD_VEHICLE` (`sets/live-animals/obligations/sections/transport.js:96-111`), matching the prototype's `requiresTransitCountries` (Rail or Road only, `app/routes.js:48`, `:2307-2313` at `04a073b`);
- the overview hides a conditional row when it is not applicable, or when none of its pages opens yet (`features/hub/controller.js:51-55`), so with no commodity saved the Transit countries page's prerequisites fail and the row is absent;
- a row reads Complete only when fulfilled, otherwise To do (`features/hub/controller.js:43-44`), so the optional, empty transit list reads To do and one country or more reads Complete.

The one gap is end-to-end: no tests-repo spec proves that, with rail or road saved and no commodity, the overview leaves the task out (the third criterion). Unit and FIT tests prove it; the real stack does not. This plan adds that integration proof and its coverage link, and changes no production code.

## 0. Decisions

1. **The rule is the means of transport, not the commodity.** The first two criteria name poultry and pet cats because the prototype traces walked "poultry by rail" and "pet cats by air" (`trace-prototype-dr2-1-p13-130`, `p13-131`). The prototype's own rule reads only the means (`requiresTransitCountries`, Rail or Road). The plan reads "poultry" as "a commodity by rail or road" and "pet cats" as "a commodity by air", and keeps the existing means-based obligation as the one owner. Rejected: a commodity-based rule, which no source states.
2. **No production change.** The row's detail ("today the Overview shows it once arrival details are saved, even with no commodity chosen") was true at animals frontend `4c2119da`, where the traces were taken. Animals frontend `2038fc3a` (#402) added the "no page opens" clause to the hidden-row check, and `arrival-transit.fit.spec.js:678-704` and `hub/copy/copy.test.js:330-344` now prove it. Rejected: salvaging `93d8eec2`, which added an `applies` rule to the task row in `flow/task-rows.js`; that would be a second owner of a rule the hub's gate check already enforces.
3. **The "To do" status for an empty but owed list stays.** The fourth criterion asks "To do until at least one transit country is selected, then Complete". The obligation is optional (a DR1 judgement recorded in `transport.js:87-95`: an empty list does not hold up submission), which the hub shows as To do because only a fulfilled row reads Complete. The overview criterion holds; submission rules are not this row's business. Rejected: making transit countries mandatory, which would change submission and contradict the check-your-answers spec ("Transit countries are not owed for submission").
4. **The integration proof extends `transit-means-scope.spec.ts`.** That spec already owns the overview's transit task by means (rail, road, air, sea, To do, Complete). The missing case — road saved with no commodity — is one more test in it. Rejected: a new spec file, or adding it to `hub-groups-and-cya-rows.spec.ts`, which proves section layout, not the transit rule.
5. **The e2e coverage link is partial.** The new test proves only the no-commodity half of the overview scenario for rail or road without origin or commodity, because `startNotification` saves the country of origin. Its link is partial and says so; the unit link from `hub/copy/copy.test.js` keeps the scenario full. Rejected: a full e2e link, which would claim the no-origin half is proven through the stack; and extending the test to that half, which would need a seeded journey.
6. **Germinal half out.** The ruling splits the germinal half to its own row; nothing under `sets/germinal-products` is touched.
7. Provenance only: criteria came from `prototype-dr2-1-source-p12-030`, `trace-prototype-dr2-1-p13-130/131`, `trace-animals-fit-p4-047/048`, `ruling:sam-2026-10-09` claim 13. The row's dependency on the arrival-and-transit means row is met (status done).
