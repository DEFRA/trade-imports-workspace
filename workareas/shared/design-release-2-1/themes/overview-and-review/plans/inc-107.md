## 0. Decisions

1. **One card per document, every card keeps the review-card id `documents`.** `REVIEW_CARDS` in
   `CA/view-model/incomplete-cards.js` is unchanged, so the "every task row exactly once" suite still holds.
   Rejected: per-document ids (`documents-1`…) — REVIEW_CARDS would need entries per document.
2. **When several cards share an id, only the first carries the anchor and the message; every one of them
   is blanked.** The error summary's "Complete documents" / virus-scan entry links to `#documents` on
   "Document 1" (one element with that id), the message reads once, and a part-filled "Document 2" still
   shows its owed rows as missing. Mirrors the commodity cards. Rejected: repeating the message on every
   card; rejected: blanking only the first card.
3. **The empty state is one "Document 1" card with one row, "Document reference" = "Not applicable"**, as
   the prototype draws it, built with `row(copy.rows.documentReference, null)`. Rejected: four rows.
4. **"Attachment" reads `entry.filename`.** A legacy entry with no `filename` reads "Not applicable" on a
   settled card. Rejected: falling back to the attachment type.
5. **Each card's Change link names its card for a screen reader: "Change document 1", "Change document 2"**
   (new copy leaf `hidden.documentN: (n) => \`document ${n}\``, Welsh `dogfen ${n}`). Every card links to
   `accompanying-documents?change=1`.
6. **Copy clean-up**: remove `cards.documents`, `hidden.cards.documents` and `documentsEmpty` (en + cy);
   rename `rows.attachmentType` → `rows.attachment` = "Attachment" / Welsh "Atodiad".
   `errors.cards.documents` stays.
7. **The template loses its nested-documents and `emptyText` branches.**
8. **Not routed through `frontend-change`** — this changes what the review reads back, not a field, page,
   section, collection, obligation or journey flow. Section 8 still applies.
9. **Integration proof in `tests/animals/e2e/features/promoted-documents.spec.ts`**, the spec that already
   uploads through the real uploader (`@compose @integration`). Two documents are uploaded.
10. **The germinal-products review is not touched.**
11. The E2E specs that assert "You have not added any documents yet." on the **documents page**
    (`promoted-documents.spec.ts`, `documents-reject.spec.ts`) stay — that page keeps the sentence.
12. **`fit/journey-smoke.fit.spec.js` follows the renamed link** ("Change document 1").
13. **The second uploaded document is `fileUploadPaths.safeFile100kbJpg`**, a tracked fixture of an accepted
    type. Rejected: `safeFile250bPng` — its file is not in the repo (gitignored), and un-ignoring PNGs to
    commit a binary is outside this slice.
14. **Document references in the new test are letters and digits only** (`PWDOCA${Date.now()}`,
    `PWDOCB${Date.now()}`), as every passing upload spec uses.
15. **No `test.slow()` sprinkling, no edits to unrelated flaky specs** (address-book, arrival-details,
    cph-number, pagination, plants journey). Their flakes are the run's, not this slice's.

```ts
test("reads each saved document back on the review in its own Document card naming its file, and a card's Change link returns to the review", async ({
  animalsJourney,
  pages,
  animalsPages,
}) => {
  test.slow();
  await animalsJourney.toAccompanyingDocuments();
  const journeyId = animalsPages.accompanyingDocuments.journeyIdFromUrl();
  const firstReference = `PWDOCA${Date.now()}`;
  const secondReference = `PWDOCB${Date.now()}`;

  await animalsPages.accompanyingDocuments.fillDocument(firstReference, '03/01/2026', fileUploadPaths.safeFile1kbPdf);
  await animalsPages.accompanyingDocuments.saveAndAddAnother.click();
  await expect(animalsPages.accompanyingDocuments.documentRow(firstReference)).toContainText('Check completed', {
    timeout: fileUploadTimeouts.virusScanComplete,
  });
  await animalsPages.accompanyingDocuments.fillDocument(secondReference, '03/01/2026', fileUploadPaths.safeFile100kbJpg);
  await animalsPages.accompanyingDocuments.saveAndAddAnother.click();
  await expect(animalsPages.accompanyingDocuments.documentRow(secondReference)).toContainText('Check completed', {
    timeout: fileUploadTimeouts.virusScanComplete,
  });

  await animalsPages.notificationView.open(journeyId);

  const firstCard = animalsPages.notificationView.summaryCard('Document 1');
  await expect(firstCard.getByRole('term')).toHaveText(['Document reference', 'Document type', 'Date of issue', 'Attachment']);
  await expect(animalsPages.notificationView.summaryValue(firstCard, 'Document reference')).toHaveText(firstReference);
  await expect(animalsPages.notificationView.summaryValue(firstCard, 'Document type')).toHaveText(
    'Intra Trade Animal Health Certificate (ITAHC)',
  );
  await expect(animalsPages.notificationView.summaryValue(firstCard, 'Date of issue')).toHaveText('03/01/2026');
  await expect(animalsPages.notificationView.summaryValue(firstCard, 'Attachment')).toHaveText(fileUploadNames.safeFile1kbPdf);

  const secondCard = animalsPages.notificationView.summaryCard('Document 2');
  await expect(animalsPages.notificationView.summaryValue(secondCard, 'Document reference')).toHaveText(secondReference);
  await expect(animalsPages.notificationView.summaryValue(secondCard, 'Attachment')).toHaveText(fileUploadNames.safeFile100kbJpg);

  await expect(animalsPages.notificationView.summaryCard('Uploaded documents')).toHaveCount(0);
  await expect(pages.page.getByText('You have not added any documents yet.')).toHaveCount(0);

  await secondCard.getByRole('link', { name: 'Change document 2' }).click();
  await expect(pages.page).toHaveURL(/\/accompanying-documents\?change=1$/);
  await animalsPages.accompanyingDocuments.continueButton.click();
  await expect(animalsPages.notificationView.heading).toBeVisible();
  await expect(pages.page).toHaveURL(/\/notification-view$/);
});
```
