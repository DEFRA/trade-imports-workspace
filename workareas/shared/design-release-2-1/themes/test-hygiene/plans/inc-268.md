  The plants journey helper exports about 60 names and the animals one about 100. Copying them all into the
  workspace guide gives one fact two homes, and it would fall behind again. Rejected: the full list.

  authority. It does not call the set guide "the full list".** The plants set guide
  (`src/server/app/sets/high-risk-plants/docs/testing.md:58-119`) does not name `errorSummary` or
  `errorSummaryLinks`, both exported from `fit/high-risk-plants-journey.js`. Claiming it is complete would make the
  workspace guide untrue. Rejected: the criterion's literal "full list" wording. Fixing the set guide is outside
  this row (repos `[]`); it is a follow-up.
- **The claims checked against the live tree:**
  - Every plants name in the table today exists, under the file the table gives (checked by export grep):
    `fit/high-risk-plants-journey.js` (all 13), `fit/set-base.js` (`BASE` as a re-export of `SET_BASE`, `setUrl`,
    `setPath`, `journeyIdFromPage`), `fit/seed-fields.js` (`seedFields`, which also takes an optional date after
    `step`), `fit/sign-in.js` (`signIn` with `{ organisationId }`).
  - The plants row is behind the code, not wrong. Helpers a new plants spec reaches for first are missing:
    `startNotificationAtOrigin`, `startNotificationAtOverview`, `saveAndReturnToHub`, `errorSummary`,
    `errorSummaryLinks`, `backLink`, `journeyFormOf`, `describeAddressPicker`, `describeDatePickerLook`,
    `withoutJavaScript`. `fit/set-base.js` also exports `pageUrlOnWalk`, `pageUrlWithTrail`, `pagePathWithTrail`,
    `notificationPageWithTrail` and `COMMODITY_REMOVED_URL`, which the row omits.
  - **The animals row is wrong, not only behind.** It names `visitOverviewThenOpen`, which
    `fit/live-animals-journey.js` does not export. Animals opens the overview with `openOverview` (`:889`) and
    a row from it with `openFromOverviewRow` (`:589`). Every other animals name exists: `signIn` is re-exported
    from `fit/sign-in.js`, and the `answer…` functions exist per section.
  - Animals has no `fit/set-base.js` or `fit/seed-fields.js`; its `fit/` holds only the journey helper and
    `sign-in.js`. The table's "both" row for `fit/sign-in.js` is right.
- **Which names count as "first reached for":** starting a notification at each entry point the helper offers,
  the save controls, the error summary and back link, the type-ahead and country choosers, opening a page from the
  overview, the accessibility check, and the `describe…` registrars that a new picker or date spec calls. The
  implementor picks the exact set from the helper files by that rule; every name kept must be an export of the file
  its row gives.
