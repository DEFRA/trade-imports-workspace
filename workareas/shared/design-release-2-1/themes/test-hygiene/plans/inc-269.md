## 0. Decisions

- **No resolutions file is needed.** The row's notes name none, and all three previews merge with no conflicts. Every resolution below is "take the merged result as is".
- **Only one file is changed on both sides: the animals commodity search FIT spec.** The theme changed its imports and error-summary helpers. Main changed the expected species, counts and order, and dropped the test for a species with no common name. The hunks do not overlap. The merged file keeps main's expectations and the theme's shared helpers (`errorSummaryLinks`, `errorSummary`, `backLink` from `fit/live-animals-journey.js`). That matches the criterion "main's behaviour with the theme's way of proving it". Rejected: re-deriving the expectations, because main's data change is what they follow.
- **Main adds no test that checks a class list, a fixed colour or a fixed alignment.** Every test main adds or changes asserts by role, accessible name, text or data: the search FIT spec, the commodity groups unit test, the stub unit test, the controller test and the tests-repo dynamics specs. So the third criterion has nothing to convert. The emphasis test's `label strong` locator was there before this change, and main only changed its expected text. It selects an element, not a class. Leave it as it is. Rejected: rewriting it, which would widen the footprint for clean-up alone.
- **The merged trees carry no dangling references.** Nothing on the theme side imports the deleted `config/animals-dynamics.ts`. No file mentions `check:signed-off-tests` or the "Signed-off pages" check. No theme test depends on a species main removed from the fixture (Catreus, Bibos, Novibos, Bison bonasus, Elephas maximus, Loxodonta africana, Ovibos, Poephagus, "Bos (Cattle)"). The tests repo has no "Republic of Ireland" left. The theme's new visual specs set no timeout of their own, so none needs `setTestTimeout`. Each was checked with `git grep` against the merged tree id.
- **The implementor edits nothing beyond the merge.** The merge itself is the change. If the gate finds a red test after the merge, the implementor fixes it under rule 6, using the theme's way of proving behaviour.
- **No ticket.** The user's instruction for this run is that a change with no `openspec/` edits needs no ticket. This row changes no spec text (section 8). The row's note also records that edits to linked tests on signed-off scenarios are already approved.
- **The pull requests' "not behind main" and "green" criteria are proved in CI, after the loop pushes.** Animals frontend #481, plants frontend #142 and tests #108 are the pull requests. A local check can only prove the branch contains `origin/main` (section 5). Mergeability and check status are read from the pull requests by the loop's later stages.
