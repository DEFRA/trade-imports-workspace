Set: `sets/live-animals` (spec namespace `live-animals/`). Routed through
`frontend-change`'s general-change lane ("change the frontend" — anything else):
this is wording, banner structure and page validation on an existing page, not a

## 0. Decisions

1. **Required fields replace the part-filled guard, exactly as the private form
   does.** The commercial controller's `recordProvided`/`missingMandatoryErrors`
   pair (`commercial-transporter-details.controller.js:97`–`:107`) only raises
   missing-field errors once some field is non-blank, so a wholly blank form saves
   nothing and walks on. Criterion 7 needs the seven messages raised outright, so
   the page's validator composition gains the required rules and the part-filled
   guard goes. Rejected: keeping the guard and adding a separate "wholly blank"
   branch — two owners for one rule, and the private twin already proves the
   one-owner shape.
2. **The country rule does not change.** Criterion 7 lists seven messages and no
   country message. `oneOf` at `commercial-transporter-details.controller.js:92`
   allows a blank and refuses any value but Northern Ireland, which is what the
   page needs: the hidden field always posts the fixed value, and a tampered one is
   still refused with today's message (the "already met" behaviour the row's notes
   name). Rejected: making country required as the private form did — the private
   form asks for a country, this one fixes it, and a required rule here would add an
   eighth message no criterion asks for.
3. **The banner's "Important" title lives in the feature's own copy, beside the
   guidance heading.** Rejected: letting govuk-frontend supply its own default
   (`node_modules/govuk-frontend/dist/govuk/components/notification-banner/template.njk:28`)
   — the default is English only, so the Welsh page would show an English title,
   breaking the programme's Welsh-draft invariant, and every other banner in this
   repo passes `titleText` from copy (`shared/layout.njk:76`, `:83`, `:98`;
   `features/dashboard/template.njk:12`). Rejected: a new key in
   `shared/copy.en.js` — a shared string nothing else would read.
4. **The guidance heading inside the banner is at heading level 2, as the design
   source sets it, and a FIT assertion on that level is what pins it.** The
   prototype's banner content opens with a level-2 notification-banner heading
   (prototype:dr2-1-source p7-089). The banner's own title is already level 2 by
   govuk-frontend's default
   (`node_modules/govuk-frontend/dist/govuk/components/notification-banner/template.njk:35`),
   and the page's other section heading (`commercial-transporter-details.njk:103`)
   is level 2, so nothing skips a level. Rejected: the level-3 heading the GOV.UK
   Design System's own banner-content example uses — the design source sets level 2.
   Rejected also: resting the level on the page's axe tests.
   `expectNoSeriousOrCriticalViolations` (`fit/live-animals-journey.js:66`) runs axe
   with the WCAG tags only and then keeps `serious` and `critical` impacts, while
   axe-core declares its heading-order rule `impact: 'moderate'` and
   `tags: [ 'cat.semantics', 'best-practice' ]`
   (`node_modules/axe-core/axe.js:32854`–`:32862`), so that rule is filtered out
   twice over and can never turn those tests red. The level is therefore asserted
   directly, by role and level, inside the banner (test 10).
5. **Only the English postcode and authorisation wording changes; the Welsh is
   already right.** Welsh has no indefinite article, so criterion 6's "a" for "the"
   has no Welsh counterpart, and the Welsh postcode strings read "cod post neu god
   zip" exactly as the private form's Welsh does
   (`copy/copy.cy.js:224`, `:234`, `:246`). The only new Welsh draft this increment
   needs is the banner title.
6. **The commercial postcode wording is brought into line with the private form's,
   not changed on both.** The private form already labels the field
   "Postcode or Zip code" and words both its messages the same way
   (`copy/copy.en.js:221`, `:231`, `:240`), as does the whole INS estate
   (`repos/trade-imports-ins-tests/domain/ins/constants/address-form.ts:7`, `:33`).
   So this is a one-side fix, and the copy test pins the two forms' agreement rather
   than restating the strings twice.
7. **`tests/animals/e2e/features/private-transporter-scope.spec.ts` leaves the
   commercial form by its cancel control instead of saving it blank.** Lines 65–68
   of that spec walk onto the commercial form and save it blank to reach the
   Overview; criterion 7 refuses that save, so the spec breaks. What it is proving
   there is that the private answers are owed only to the private type, and the
   wipe happens at the type question's own commit, not at the commercial save. So
   the spec leaves the form by its cancel control and reopens the Overview by
   reference, as it already does at line 53. Rejected: filling and saving the
   commercial form through `flows/animals/journey.ts:653` — it would persist a
   second address-book transporter under a name a sibling spec already uses,
   widening the spec's data footprint for no extra proof.
8. **The commercial end-to-end proof extends the one test in
   `tests/animals/e2e/features/commercial-transporter-scope.spec.ts` rather than
   adding a second.** That is the shape the private twin uses
   (`private-transporter-scope.spec.ts` carries the browser title, the blank-save
   refusal and the scope rule in one journey). Rejected: a second test in the same
   file or a new spec file — each would re-walk the whole journey to the transporter
   step to assert page copy.
9. **`recordProvided` stays as an argument to the shared save helper.** Once every
   mandatory field is required, a commercial save that passes validation always
   carries a record, so the helper's `!recordProvided` branch
   (`transporter-details-save.js:118`) becomes unreachable from both add forms (the
   private form reached that state one increment ago). Collapsing it would change
   the helper's shape and both call sites, which this row does not need. Left as a
   follow-up (section 7).
10. **Every E2E assertion this row adds reads the page through accessors the
    commercial page object already inherits; no locator is added to it for the
    banner or the error summary.** `AnimalsCommercialTransporterPage`
    (`page-objects/animals/commercial-transporter-page.ts:20`) extends
    `NotificationPage` (`page-objects/shared/base-page.ts:233`), which extends
    `BasePage`, so `importantBanner` (`base-page.ts:62`), `errorSummary`
    (`:66`) and `errorSummaryLinks` (`:74`) are already on it. Three specs read
    banners through the first of those
    (`tests/animals/e2e/features/amend-from-a-later-session.spec.ts:50`,
    `tests/plants/e2e/features/amend-from-a-later-session.spec.ts:28`,
    `tests/animals-admin/e2e/features/admin-notifications.spec.ts:120`), and the
    private twin reads its refusal through the last
    (`tests/animals/e2e/features/private-transporter-scope.spec.ts:23`). Rejected: a
    banner getter on the commercial page object built from
    `notificationBannerTitled` — a second home for one locator and a local copy of a
    shared accessor's body.
11. **The comment above the fixed country control keeps only what the two lines
    beneath it cannot say in markup.** Its rationale half — why a hand-entered
    commercial transporter can only be Northern Irish, and so why the country is
    shown and fixed — is already carried by the repo's own doc
    (`src/server/app/sets/live-animals/docs/page-design.md:568`–`:571`) and by the
    capability's Purpose
    (`openspec/specs/live-animals/journey-pages/commercial-transporter-details/spec.md:5`),
    and the house rules put rationale there, not in code. The template is edited for
    this row's own behaviour, so bounded tidy-up puts the whole file in scope.
    Rejected: leaving the comment whole because the row's own change is a few lines
    above it — a scope limits which files are opened, not which lines of an opened
    file are fixed.
12. **The stale FIT test name in the capability's coverage is corrected in this
    row.** `coverage.json:43` names a test that does not exist in the file it cites;
    `tim spec lint` on this capability returns 0 findings today, so nothing else
    catches it, and this row already rewrites that scenario block. Rejected: a
    follow-up row — the plan is the only place it gets noticed, and the block is
    already being edited.
