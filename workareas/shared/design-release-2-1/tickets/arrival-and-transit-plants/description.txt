h3. Background

Design Release 2.1 rewords the arrival details page of a high-risk plants notification so it reads consistently with the live animals equivalent.

The place-of-landing question gets the same style of hint as the animals port of entry, and the arrival questions are all set at the same size. Each port in the place-of-landing list reads its name with its code, which also works when the page is used without JavaScript.

*The plants journey keeps its own questions.* Plants asks for a proposed place of landing and an expected date and time of arrival, which differ from the animals page; what changes is how those questions read, not which questions are asked.

This ticket covers the *high-risk plants journey only*. The same increments changed the live animals journey, which has its own ticket under the same epic. The work is not yet merged.

h3. What changes for the user

h4. The place of landing is hinted like the animals port of entry

The hint now tells the trader what the field is for and that they can search by name or code, in the same words as the animals journey uses for its port of entry.

h4. The arrival questions read at one size

On a potatoes notification, the expected date of arrival, expected time of arrival and proposed place of landing questions are all set at the medium size. On a plants or wood notification, the arrival date question is too.

h4. Ports read with their code, with or without JavaScript

Each port in the place-of-landing list reads "<port name> - <port code>". Without JavaScript the page falls back to an ordinary list, which is labelled as the place-of-landing question and reads its ports the same way, and the chosen port is still held when the trader returns.

h3. Acceptance criteria

Copied from the service's behaviour specification. All 4 scenarios for the plants journey are listed in full.

h5. The place of landing is hinted as the animals port of entry is

* *GIVEN* a potatoes notification is on the arrival details
* *WHEN* the page loads
* *THEN* the place of landing hint reads "Select where the potatoes will enter Great Britain. Start typing to search by port or airport name or code."

h5. A potatoes notification's arrival questions read at medium size

* *GIVEN* a potatoes notification on arrival details
* *WHEN* the page loads
* *THEN* the expected date of arrival, expected time of arrival and proposed place of landing questions are each set in the medium label size

h5. A plants or wood notification's date question reads at medium size

* *GIVEN* a plants or wood notification on arrival details
* *WHEN* the page loads
* *THEN* its arrival date question is set in the medium label size

h5. A potatoes notification chooses its place of landing from an ordinary list

* *GIVEN* a potatoes notification is on the arrival details without JavaScript
* *WHEN* they choose a port from the ordinary list, complete the page and save it
* *THEN* the list is labelled as the place of landing question and each port reads "<port name> - <port code>"
* *AND* returning to the page still holds that port's code
