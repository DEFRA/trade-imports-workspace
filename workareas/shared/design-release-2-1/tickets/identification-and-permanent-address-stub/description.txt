h3. Background

This is the Design Release 2.1 theme covering the live animals Identification details page and the permanent address page: which identifier a species is asked for, how a species panel saves and refuses an entry, and the permanent address a trader gives for cats, dogs and ferrets, including reading those addresses back on the consignment addresses and review pages. It holds twelve rows, ten of them ready to build.

The work has not started yet. This ticket exists now so the branch the theme builds on can carry its number, and so the Import notification service board shows the theme before any code lands.

The description below is filled in automatically from the behaviour specification once the theme has been built, and is regenerated whenever that specification changes. There is nothing to review here until then.
