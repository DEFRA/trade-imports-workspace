h3. Background

Every page of the Import notification service front door now carries a title that follows the GOV.UK pattern: the page's own name, then the service name, then GOV.UK, separated by hyphens.

A page title is what a browser shows in its tab and its history, what a screen reader announces first when a page loads, and what a search result or a bookmark is named after. Getting it wrong makes a service harder to navigate for anyone using several tabs, and harder still for a screen reader user, who hears the title before anything else on the page.

Before this change the front door's titles did not follow the pattern, and the home page was not titled "Dashboard". This ticket covers the *front door only*. The same increment changed page titles in the high-risk plants journey, which has its own ticket under the same epic. *This work is merged to {{main}}.*

h3. What changes for the user

Each named page of the front door — the address book, for instance — is titled with its own name first, then the service, then GOV.UK, joined by hyphens rather than pipes. The home page is titled "Dashboard". A page showing an error summary opens its title with "Error:", so a screen reader user hears that something needs attention before anything else. A page that does not exist is titled "Page not found".

h3. Acceptance criteria

Copied from the service's behaviour specification. All 5 scenarios are listed — this change's specification is small enough to give in full.

h5. A page's title reads page name, service name, GOV.UK

* *GIVEN* a signed-in trader is on a page of the front door that carries a name of its own, such as the address book
* *WHEN* the page's title is read
* *THEN* it reads that page's name, then the service name, then GOV.UK, joined by hyphens, such as {{Address book - Import notification service - GOV.UK}}

h5. The parts are not separated by a pipe

* *GIVEN* a page of the front door
* *WHEN* its title is built
* *THEN* no pipe separates the page name, the service name and GOV.UK

h5. The home is titled Dashboard - Import notification service - GOV.UK

* *GIVEN* a signed-in trader
* *WHEN* they open the home
* *THEN* the title reads {{Dashboard - Import notification service - GOV.UK}}

h5. The error prefix opens the title while errors are shown

* *GIVEN* the trader has submitted a page that answers back with an error summary, such as the add address page with nothing filled in
* *WHEN* the page's title is read
* *THEN* it opens with the error prefix, followed by the page's name, the service name and GOV.UK as before, such as {{Error: Add address details - Import notification service - GOV.UK}}

h5. A page that does not exist is titled Page not found - Import notification service - GOV.UK

* *GIVEN* a signed-in trader
* *WHEN* they open a page that does not exist
* *THEN* the title reads {{Page not found - Import notification service - GOV.UK}}
