h3. Background

Design Release 2.1 tidies the country of origin question on a high-risk plants notification: the field loses its hint text, and its empty state reads as the design words it.

That is the whole of the change for plants. The same increment made larger changes to the live animals origin page — a region of origin code, territories in the country list, a reworded internal reference — and none of those apply here. *Plants keeps its own questions*; only the country field's presentation changes.

This ticket covers the *high-risk plants journey only*. The live animals origin page has its own ticket under the same epic. The work is not yet merged.

h3. What changes for the user

The country of origin question no longer shows hint text under it. With JavaScript the field is a search box showing "Search for a country"; without JavaScript it is an ordinary list beginning with a blank "Select a country" entry. Either way the field is labelled "Country of origin", and a country chosen from the plain list is saved and shown back on return.

h3. Acceptance criteria

Copied from the service's behaviour specification. Both scenarios for the plants journey are listed in full.

h5. With JavaScript, the empty search box shows "Search for a country" and no hint

* *GIVEN* the user has reached the origin of the import page with JavaScript available and no country chosen
* *WHEN* the page loads
* *THEN* the country field, labelled "Country of origin", shows the placeholder "Search for a country"
* *AND* no hint text is shown for the country question

h5. Without JavaScript, the country list begins with "Select a country", shows no hint, and saves the chosen country

* *GIVEN* the user has reached the origin of the import page without JavaScript
* *WHEN* they read the country list, choose a country from it and save and continue
* *THEN* the list, labelled "Country of origin", began with its blank "Select a country" entry and no hint text was shown
* *AND* returning to the page shows that country chosen
