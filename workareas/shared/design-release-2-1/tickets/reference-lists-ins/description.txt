h3. Background

The country field on the address book's add-address form now offers every country master reference data (MDM) serves, through the reference data service, rather than a short hand-typed list held in the code.

Before this change the front door's stub mode offered four hand-typed countries, so an address outside those four could not be recorded correctly. The field now offers United Kingdom first — the common case for an address book used by GB traders — then every country the reference data service serves, by its served name, in the order the service serves them.

No country is added, removed or respelt by hand. Whatever MDM serves is what a user sees, so a change in MDM reaches the service without a code change.

This ticket covers the *Import notification service front door only*. The same increment changed the country and port lists in the live animals and high-risk plants journeys, each of which has its own ticket under the same epic. The work is not yet merged.

h3. What changes for the user

Adding an address to the address book asks for a country. That field now offers United Kingdom, then every country the reference data service serves. Any country MDM knows about can be recorded, which was not previously true.

h3. Acceptance criteria

Copied from the service's behaviour specification. This change has one scenario, given in full.

h5. The country field offers United Kingdom, then every country the reference data service serves

* *GIVEN* the user opens the add address form
* *WHEN* the country list is read in full
* *THEN* after its placeholder it offers United Kingdom, then every country the reference data service serves, by their served names, in the order it serves them
