h3. Placeholder

This is the Design Release 2.1 transporters theme: the transporter list, the transporter type question, the two add forms, and the Import notification service address book's transporter type, tab and details page. It holds 13 rows across the live animals frontend, the Import notification service front door, the address book, the Import notification service backend, the upstream stub and the test suite.

The theme was unblocked on 6 November by the decision that the address book manages transporters as per-organisation records, like every other address, and that adding one mid journey uses the address book hand-off already built for addresses. Two rows stay blocked: the Northern Ireland address search waits on the Import notification service address lookup becoming a real feature, and approved transporters are parked.

This ticket exists to give the theme's branch a number. Its description and its acceptance criteria are filled in automatically from the behaviour specification once the build completes, and the theme is then split into one Story per service domain.
