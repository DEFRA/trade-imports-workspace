2. **Journey order is being redesigned live, page by page.** Contact address goes: hub item (before

3. **Validation added on Monday, deleted on Tuesday.** 33f5836 adds arrival-date range validation

4. **Duplicated completeness logic.** `hasAllNotificationHubSectionsComplete`,

7. **Query-string mode flags as the navigation idiom.** `?from=hub`, `?from=review`,

8. **Reuse one Nunjucks template for multiple modes** via locals flags: `address-book-lookup.html`
