## Blocker (all 8 trials): remount.test.js failed once any release existed

- `scripts/designer/release/test-repo.js`: `makeTestRepo` now runs `remountReleases({ repoRoot })` before its first commit. This is the trial fix (be12a2c and the others) ported. It also takes `{ from }`, so a test can copy a checkout that holds a release.
- New regression test, `remount.test.js` "Should start every test repo without the releases of the checkout it copies". It starts a release in one test repo, copies it, and checks the copy mounts nothing extra. It fails without the fix.
- `scripts/new-set/index.test.js` also copies the live mount files, so it now remounts the same way (hermetic, not relying on luck).
- The PR canary (`check-pull-request.yml` release-canary) already runs the full unit suite with a throwaway release mounted, so it would have caught this on a PR. It was not changed.
