    feat(parity-dr1): Frontend labels the package count "Number of packages (optional)"; Design release 1 labels it "Number of packages (when required)". (#239)
    
    Relabel the per-commodity package count on the consignment details page from
    "Number of packages (optional)" to "Number of packages (when required)", to
    match Design release 1. "(optional)" is the GOV.UK convention for a field the
    user may always skip, so it told the user the count never matters; Design
    release 1's wording says there are circumstances in which it has to be given.
    
    - English copy: commodities copy.en.js packages label
    - Welsh copy: commodities copy.cy.js packages label ("Nifer y pecynnau (pan fo angen)")
    - Updated the Playwright specs that select the field by its label (shared
      live-animals journey helper, additional-details, hub)
    - Added an accessible-name assertion on the packages input in the consignment
      details fit spec so the label is now covered by a test, and pulled the
      repeated "numberOfPackages-0" selector into a named constant
    
    Neither side validates the box for live animals today, so the wording is the
    only place the user is told anything about when the count matters. If "when
    required" turns out to mean a rule rather than a hint, that rule is separate
    work and Design release 1 does not state it.
