56:# Probe Dockerhub for a branch tag and print a stable fingerprint of its

62:# branch tag apart from a re-pushed one. bash-3.2 safe.

131:# Fan out the branch-tag probes concurrently. docker manifest inspect is a
132:# network round-trip per service; running them in parallel turns 9 sequential
133:# round-trips into one wall-clock round-trip. Each job touches a marker file on
134:# success; the print loop below reads the markers so all env-var exports still

136:# only mktemp -d, background jobs, and a bare wait barrier are used.
138:# The marker directory holds one file per service that resolved to the branch
