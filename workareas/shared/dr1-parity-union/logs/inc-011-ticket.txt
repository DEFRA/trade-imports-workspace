h2. Increment

{{inc-011}} from the {{shared/dr1-parity-union}} backlog.

Every browser tab, bookmark and screen-reader page announcement in the frontend reads {{Origin of the import | Import notification service}} — page name, a pipe, service name, and nothing more. All 33 captured frontend screens follow it, because the title is composed once at {{src/server/app/shared/layout.njk:17}}. DR1 titles every page {{Origin of the import - Import notification service - GOV.UK}}, and that hyphen-and-GOV.UK form is also the GOV.UK Design System's documented title convention, which the pipe form is not.

h2. Acceptance criteria

* The shared layout at {{src/server/app/shared/layout.njk}} composes every page title as the page name, the service name and {{GOV.UK}} joined by hyphens, so a page reads {{Origin of the import - Import notification service - GOV.UK}}.
* The {{Error:}} prefix the frontend already adds when a page shows validation errors survives the change and sits in front of the whole title.
* No feature copy changes. Each view still supplies only its own page name, and the surrounding format stays composed in one place.
* Every spec that asserts on a full page title is updated to the new format, in the frontend repo and in the tests repo.
* Welsh titles follow the same composition as English, using the Welsh copy already in {{src/server/app/shared/copy.en.js}} and its Welsh pair.

h2. Falsified by

Finding any frontend page whose title already ends in {{- GOV.UK}}, or any DR1 page whose title uses a pipe.
