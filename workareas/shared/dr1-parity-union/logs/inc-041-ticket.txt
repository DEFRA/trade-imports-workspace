h2. Increment

{{inc-041}} from the {{shared/dr1-parity-union}} backlog.

DR1 tags a hub task either {{Complete}} or {{To do}} and has no third state. The frontend uses four: {{Completed}}, {{In progress}}, {{Not yet started}} and {{Optional}}. Reduce the hub's status vocabulary to DR1's two.

h2. Acceptance criteria

* The hub renders exactly two task statuses, {{Complete}} and {{To do}}, and every row carries one of them.
* A finished task reads {{Complete}}; every task that is not finished reads {{To do}}.
* The part-done state, shown today as {{In progress}}, no longer appears on the hub.
* The {{Optional}} grey text on the uploaded documents row is gone; that row reads {{To do}} like any other unstarted task.
* The tags themselves are unchanged: {{govuk-tag--green}} for {{Complete}}, {{govuk-tag--blue}} for {{To do}}.
* The wording lives in {{src/server/app/sets/live-animals/journeys/linear/features/hub/copy/copy.en.js}} and the state mapping in {{src/server/app/sets/live-animals/journeys/linear/features/hub/controller.js}}.
* Out of scope: the blocked-row phrase {{Cannot start yet}}, which is inc-032, and whether documents are optional to submit, which belongs to the documents slice.
* Unit tests and the E2E specs, visual baselines included, are updated to the new wording.

h2. Falsified by

A DR1 hub row rendered with any status text other than {{Complete}} or {{To do}}.
