h2. Increment

{{inc-084}} from the {{shared/dr1-parity-union}} backlog.

Frontend heads the quantities page "Consignment details"; Design release 1 heads the same page "Commodity details".

The page that lists what has been chosen and asks for a count per species is headed "Consignment details" in the frontend, with the string held once in the commodities copy file and reused as the heading, the browser tab title and the last breadcrumb. Design release 1 heads the same page "Commodity details", and uses that name for the hub task that opens it too, so a user who clicks a task arrives at a page carrying the task's own name. "Consignment" is used on Design release 1 only for the caption above the heading, "About the consignment", which sits over several pages of this section.

h2. Acceptance criteria

* The quantities page heading reads "Commodity details" instead of "Consignment details".
* The page title is renamed in {{src/server/app/sets/live-animals/journeys/linear/features/commodities/copy/copy.en.js}}, which carries the string once and feeds the heading, the browser tab title and the breadcrumb together, so all three change at once.
* The Welsh copy file beside it carries the same title and is renamed with it.
* Any spec that asserts the heading or the title on this page is updated to the new wording.
* The section caption above the heading is NOT changed — that is a separate service-wide difference.
* The shape of the browser tab title (the hyphen-and-GOV.UK format) is NOT changed — that is its own service-wide finding and independent of this one.
