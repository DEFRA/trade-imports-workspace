h2. Increment

{{inc-085}} from the {{shared/dr1-parity-union}} backlog.

The "Help with commodity codes" details on the commodity search page reveals a single sentence — "Commodity codes are used to classify goods for import and export." — and nothing else. It is passed to the {{govukDetails}} macro as plain text, so it cannot carry a link. A user who does not know their commodity code is told what one is and left with no way to find it.

Design release 1 holds the details of the same name, in the same position on the page, with three paragraphs and a link out to the Trade Tariff tool.

h2. Acceptance criteria

* The "Help with commodity codes" details on the commodity search page shows three paragraphs: "Commodity codes are internationally recognised reference numbers.", "A commodity code describes a specific product when importing or exporting goods.", and "You can look up commodity codes using the Trade Tariff tool (opens in a new tab)."
* "Trade Tariff tool" is a link to https://www.gov.uk/trade-tariff that opens in a new tab. The "(opens in a new tab)" text sits outside the anchor, after a line break, matching Design release 1.
* The copy entry carries HTML rather than plain text, and the details is rendered through the HTML parameter of {{govukDetails}} rather than the text parameter.
* The Welsh copy file beside it gets the same treatment — three paragraphs and the same Trade Tariff link.
* No other copy on the commodity search page changes.
