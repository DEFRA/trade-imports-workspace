h2. Increment

{{inc-089}} from the {{shared/dr1-parity-union}} backlog.

The commodities consignment-details page labels the package-count field "Number of packages (optional)" ({{src/server/app/sets/live-animals/journeys/linear/features/commodities/copy/copy.en.js}} lines 32-35, rendered by {{_species-quantities.njk}}). Design release 1 labels the same field, in the same position and under the same hint, "Number of packages (when required)" ({{app/data/commodities.js}} lines 21-23). "(optional)" is the GOV.UK convention for a field a user may always skip, so it tells the user the count never matters, which is the opposite of what Design release 1 says.

Neither side validates the box for live animals today — Design release 1 validates the count only on germinal lines, which its users cannot create — so the wording is the only place a user is told anything about when the count matters. If "when required" turns out to mean a rule rather than a hint, that rule is separate work and Design release 1 does not state it.

h2. Acceptance criteria

* The package-count label in {{copy.en.js}} reads "Number of packages (when required)" in place of "Number of packages (optional)".
* The Welsh copy file beside it carries the same label change.
* The hint beneath the field still reads "Such as crates, bags or boxes", unchanged.
* Every commodity line that asks for packages shows the new label, on each commodity that asks for it.
* No validation rule is added for the package count — the label change is the whole of this increment.
