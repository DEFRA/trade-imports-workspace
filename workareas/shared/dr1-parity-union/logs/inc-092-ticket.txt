h2. Increment

{{inc-092}} from the {{shared/dr1-parity-union}} backlog.

Each Number of animals input in the frontend carries the hint "For example, 1, 25 or 5000." ({{src/server/app/sets/live-animals/journeys/linear/features/commodities/copy/copy.en.js:27-30}}, rendered at {{src/server/app/sets/live-animals/journeys/linear/features/commodities/consignment-details/_species-quantities.njk:11-20}}). On a consignment with several species the hint repeats under every line.

Design release 1's Number of animals input has a label and nothing else — no hint element and no {{aria-describedby}} on the input — where the packages input on the same page does carry a hint ({{app/views/consignment-details.html:105-114}}). The two sides agree on the packages hint word for word, so the difference is confined to this one field.

h2. Acceptance criteria

* The hint "For example, 1, 25 or 5000." is removed from the Number of animals field in the commodities copy file, in English and in Welsh.
* The hint argument is dropped from the Number of animals input in {{_species-quantities.njk}}, so the rendered input has no hint element and no {{aria-describedby}} pointing at one.
* The packages hint on the same page is left exactly as it is — it already matches Design release 1 word for word.
* The Number of animals label itself is unchanged, and the field keeps its existing validation and error messages.
* Unit and component tests covering the quantities page pass, with any snapshot or assertion that expected the animals hint updated to the new markup.
