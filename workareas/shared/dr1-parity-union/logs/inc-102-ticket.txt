h2. Increment

{{inc-102}} from the {{shared/dr1-parity-union}} backlog.

The frontend heads its two identification pages "Animal identification details" and "Additional animal details". Design release 1 names the same two pages "Identification details" and "Additional details", and carries the orientation in a section caption above the heading instead of inside it.

Each page name is used three times on its page — as the h1, as the last breadcrumb and as the browser tab title — and each name lives once, in its feature's copy file, so one string per page feeds all three.

h2. Acceptance criteria

* The identification page is named "Identification details" — the h1, the last breadcrumb and the browser tab title all read that, in English and in Welsh.
* The additional details page is named "Additional details" — the h1, the last breadcrumb and the browser tab title all read that, in English and in Welsh.
* Neither page name contains the word "animal" anywhere it is shown to a trader.
* The identification page name is changed in {{src/server/app/sets/live-animals/journeys/linear/features/commodities/copy/copy.en.js}} and its Welsh counterpart, as a single string feeding heading, breadcrumb and title.
* The additional details page name is changed in {{src/server/app/sets/live-animals/journeys/linear/features/additional-details/copy/copy.en.js}} and its Welsh counterpart, as a single string feeding heading, breadcrumb and title.
* Scope is the two pages' own names only. The hub task-row labels are a separate increment and are not changed here.
* Unit tests and E2E specs that assert either old page name are updated, and the frontend and tests suites pass.
