h2. Increment

{{inc-105}} from the {{shared/dr1-parity-union}} backlog.

The animal identification page shows nothing between the inset text and the first commodity card, so what the consignment holds is readable only by scrolling the identifier forms themselves. Design release 1 opens the page with a *Selected commodities* summary — commodity code, common name and number of animals per row, a Change link per row back to the commodity answers, and an Add another commodity link beneath.

h2. Acceptance criteria

* A *Selected commodities* summary renders above the identification cards on {{src/server/app/sets/live-animals/journeys/linear/features/commodities/animal-identification/animal-identification.njk}}, one row per commodity.
* Each row shows the commodity code, the common name and the number of animals for that commodity.
* Each row carries a *Change* link back to the frontend's commodity page. The frontend's picker is a fixed checkbox list rather than Design release 1's search, so the destination is the commodity page, not a search reset.
* An *Add another commodity* link renders beneath the summary, and it is no longer conditional on the notification having no commodities — today the page's only Add a commodity link sits in the empty-state branch and disappears once the page becomes usable.
* The existing consignment-details table at {{src/server/app/sets/live-animals/journeys/linear/features/commodities/consignment-details/_selected-commodities-table.njk}} is reused where it helps, but it is not a straight lift — it has no number-of-animals column and its row action is Remove rather than Change.
* The number of animals comes from the existing view model line in {{src/server/app/sets/live-animals/journeys/linear/features/commodities/consignment-details/view-model/groups.js}}, which already carries it.
* The consignment-details page keeps its current Selected commodities table and its Remove action unchanged.
* Unit and E2E tests cover the new summary, and the tests repo's specs and visual baselines are updated for the changed page.
