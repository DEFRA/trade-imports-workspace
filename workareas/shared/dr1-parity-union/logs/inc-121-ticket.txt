h2. Background

The commercial transporter selection page {{/transporters/select}} is headed "Search for an approved commercial transporter" and offers no way to search. It renders one line of guidance and then the whole commercial-transporter list as radios, each labelled with the transporter's name and hinted with its address and approval number ({{src/server/app/sets/live-animals/journeys/linear/features/transport/transporters-select/transporters-select.njk}} lines 11-23, {{src/server/app/sets/live-animals/journeys/linear/features/transport/copy/copy.en.js}} lines 90-93). There is no text input, no search button and no filtering of any kind. The page promises a search it does not have, and the promise gets less true as the list grows.

Design release 1 puts a labelled Search field, hinted "Name, address or approval number", directly above its table of transporters ({{app/views/transporter.html}} lines 75-95). Note that DR1's own filter is JavaScript only — its search button is {{type="button"}} and the form post reads the search field then ignores it — so DR1's behaviour is not a progressive-enhancement model worth copying as-is.

h2. Acceptance criteria

* A search input sits above the commercial transporter list on {{/transporters/select}}, labelled *Search* and hinted "Name, address or approval number".
* Submitting the search filters the transporter list to records whose name, address or approval number matches the search string. Filtering works on submit, server-side, so a user without JavaScript still gets a filtered list.
* Matching is case-insensitive and matches on a substring of any of the three fields.
* An empty or cleared search shows the full list again.
* When the search matches no transporters the page says so in plain English rather than showing an empty radio group.
* The user's current selection and the search term survive the filter round trip — filtering does not lose a transporter the user had already chosen.
* The page keeps its h1 "Search for an approved commercial transporter", which is now true of the page.
* The search field, its label and its hint use the govuk-frontend toolbox — no custom CSS and no hand-rolled components.
* Unit tests cover the filter over each of name, address and approval number, the no-match case and the empty-search case.
* The E2E specs and visual baselines in {{trade-imports-animals-tests}} are updated for the new control.
