h2. Acceptance criteria

* The confirmation page shows a second link, "Create a new notification", below "Return to your dashboard" in the "How to view or amend this notification" block.
* The two links sit on separate lines, matching Design release 1.
* The new link points at the same route the dashboard's start action uses, the start of the live animals notification journey.
* The link text comes from the confirmation feature's copy file {{src/server/app/sets/live-animals/journeys/linear/features/confirmation/copy/copy.en.js}}, not hard-coded in the template.
* The existing "Return to your dashboard" link is unchanged in wording and destination.
* The end-to-end specs and any visual baselines that cover the confirmation page are updated to match.
