### 2.2 `fixtures/auth-state.ts` (clean-but-wrong)

Git's merge keeps main's `AuthTarget` type, which has no `cookieName`, and main's `authCookieNameFor(targetName, baseURL)`. It also keeps the branch's plants `cookieName` line. That line doesn't compile, and nothing reads it, so plants would mint `sid` on the local stack.

a. Replace the block from `const INS_COMPOSE_AUTH_COOKIE_NAME = 'ins-sid';` through the closing `};` of `authCookieNameFor` with:

```ts
const LOCAL_STACK_HOSTS = ['localhost', '127.0.0.1', 'cdp-docker.test'];

const COMPOSE_AUTH_COOKIE_NAMES: Record<string, string> = { ins: 'ins-sid', plants: 'plants-sid' };

const isLocalStackUrl = (baseURL: string): boolean => {
  const url = baseURL.toLowerCase();
  return LOCAL_STACK_HOSTS.some((host) => url.includes(host));
};

/** ins and plants mint their own development session cookie (ins-sid, plants-sid) on the local stack — see frontend.compose.yml and each frontend's auth.cookieName default. Every other target, and every service outside the local stack, uses sid. AUTH_SESSION_COOKIE_NAME overrides all of them. */
export const authCookieNameFor = (targetName: string, baseURL?: string): string => {
  if (process.env.AUTH_SESSION_COOKIE_NAME) {
    return process.env.AUTH_SESSION_COOKIE_NAME;
  }
  const composeCookieName = COMPOSE_AUTH_COOKIE_NAMES[targetName];
  if (composeCookieName && baseURL && isLocalStackUrl(baseURL)) {
    return composeCookieName;
  }
  return AUTH_COOKIE_NAME;
};
```

Keep `export const AUTH_COOKIE_NAME = 'sid';` above it. Keep the braced `if` style: it matches main's version of this function. Prettier may re-wrap the doc comment. Run the repo's own `format` if the gate's format check fails, and change nothing by hand.

b. In `AUTH_TARGETS`, replace the multi-line `plants: { … cookieName: process.env.AUTH_SESSION_COOKIE_NAME ?? 'plants-sid', },` entry with main's single line:

```ts

```

Leave `e2e`, `admin` and `ins` exactly as merged.

c. Leave the `AuthTarget` type as merged, with no `cookieName`. Leave the `createAuthState` call `authCookieNameFor(targetName, baseURL)` as merged. Don't touch `stripToAuthCookie`, `COLD_START` or `bin/cdp-session-probe.ts`: the probe still passes the default `sid`, which is correct for its CDP-only targets.
